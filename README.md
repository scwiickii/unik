# Uniqualizer — приложение для уникализации видео

## Что делает
Выбираешь видео на телефоне, отмечаешь галочками нужные эффекты
(обрезка начала/конца, зеркало, насыщенность, оттенок, шум, обрезка
краёв, скорость, водяной знак картинкой, случайные метаданные),
жмёшь «Обработать» — получаешь готовый файл в `Movies/Uniqualizer`
и можешь сразу «Поделиться» им.

## Как собрать APK (через GitHub Actions — без своего компьютера)

1. Зайди на github.com с телефона, создай новый **публичный или приватный
   репозиторий** (например `uniqualizer`).
2. Загрузи в него все файлы из этого архива, сохранив структуру папок
   (важно, чтобы `.github/workflows/build-apk.yml` остался именно по
   этому пути — GitHub на мобильном сайте позволяет загружать файлы
   через кнопку "Add file -> Upload files", папки создаются сами при
   указании пути в имени файла).
3. Открой вкладку **Actions** в репозитории — сборка запустится
   автоматически после загрузки файлов (или нажми "Run workflow"
   вручную, если не запустилась).
4. Первая сборка идёт **15–25 минут** (Android SDK/NDK скачиваются
   с нуля). Последующие — быстрее благодаря кэшу.
5. Когда сборка завершится (зелёная галочка), открой её и внизу
   страницы найди раздел **Artifacts** — там будет `uniqualizer-apk`.
   Скачай и распакуй (это zip с APK внутри).
6. Установи APK на телефон. Android спросит разрешение на установку
   "из неизвестных источников" — разреши для этого файла.

## После установки

- При первом запуске приложение запросит доступ к файлам — разреши.
- На Android 11+ может понадобиться дополнительно зайти в
  **Настройки -> Приложения -> Uniqualizer -> Разрешения -> Файлы и
  медиа -> Разрешить управление всеми файлами** — без этого выбор
  видео из произвольных папок может не работать.
- Видео и картинку для водяного знака выбираешь через встроенный
  файловый браузер (открывается на папке Movies/DCIM/Pictures).

## Если сборка упала с ошибкой

Открой лог упавшего шага в Actions — обычно это либо:
- не хватает памяти раннера (редко, можно перезапустить workflow),
- версия `ffmpeg-kit-full` временно недоступна в Maven — в этом
  случае в `buildozer.spec` попробуй заменить
  `com.arthenica:ffmpeg-kit-full:6.0-2` на
  `com.arthenica:ffmpeg-kit-min-gpl:6.0-2` (более лёгкая сборка
  ffmpeg, но без части кодеков).

## Локальный тест интерфейса на ПК (по желанию)

Если у тебя будет доступ к компьютеру, можно проверить интерфейс
до сборки APK:

```bash
pip install kivy plyer
python main.py
```

На ПК обработка пойдёт через системный `ffmpeg`/`ffprobe` (должны
быть установлены и доступны в PATH) — на телефоне это не нужно,
там всё делает встроенный FFmpegKit.
